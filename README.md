# KFCku App Redesign

A **UI/UX redesign project** focused on improving the ordering experience of the KFCku mobile application through user research and interface redesign.

## Overview

The project explores usability issues in the existing ordering experience and translates user needs into a more intuitive and streamlined interface.

The redesign process covers **user research, wireframing, and high-fidelity prototyping**, with a focus on improving navigation, ordering flow, and overall user experience.

## Key Highlights

- User research to identify user needs and pain points
- Redesigned ordering flow
- Improved information hierarchy and navigation
- Wireframe to high-fidelity prototype
- Interactive mobile app prototype

## Design Process

**User Research → Wireframe → High-Fidelity Prototype**
